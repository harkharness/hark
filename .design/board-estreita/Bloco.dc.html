A caixa do bloco: o vazio das cercas vira padding
hoje — a caixa cobre as três linhas inteiras (~64 px para uma linha de código)
```js const x = "a"; ```
65
proposta — a caixa recua meia linha de cada lado (~39 px, mesmo texto)
```js const x = "a"; ```
39
As linhas ``` continuam ocupando altura — elas existem no texto e o caret anda por elas, então não dá para encolhê-las sem soltar o caret das letras. O que dá é a caixa não reivindicar a linha toda: ela recua ~10 px em cima e embaixo, e o que sobra da cerca lê como o respiro do bloco.
