1# Hark
2
3[![test](https://github.com/jhonmike/hark-harness/actions/workflows/test.yml/badge.svg)](https://github.com/jhonmike/hark-harness/actions/workflows/test.yml)
4
5A local, voice-first cockpit for [Claude Code](https://code.claude.com). Talk to
6your machine like JARVIS: ask what you were working on, hear the answer out
7loud, and dispatch real work into your existing Claude Code sessions — by voice
8or text, across every project on your disk.
9
10Hark never calls the Anthropic API directly. It drives the `claude` CLI you
11already have installed and authenticated, so all usage draws from your existing
12subscription. No API key, no separate billing, no telemetry.
13
14> Status: a working desktop app in active development (macOS, Apple Silicon
15> and Intel; Linux is on the backlog). Expect sharp edges; the voice loop,
16> windows, boards, cost ledger and the persistent assistant chat all work today.
17
18## Install (from a release)
19
20Binaries ship from the PUBLIC releases-only repo
21([harkharness/hark](https://github.com/harkharness/hark)) — this source repo
22stays private and is never exposed through them. Anyone can install with:
23
24```bash
25curl -fsSL https://harkharness.web.app/install.sh | bash
26```
27
28That downloads the latest public release for your architecture, installs the
29`hark` CLI into `~/.local/bin`, drops `hark.app` into `/Applications` and
30clears the quarantine bit (the app is not code-signed yet).
31
