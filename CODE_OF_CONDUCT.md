# Code of conduct

Hark follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be welcoming, be kind, assume good faith, and keep criticism about
the work.

Report unacceptable behavior privately to the maintainer at
jhon.msdev@gmail.com. Every report is reviewed and kept confidential.
