<Aside type="caution" title="Hark está en desarrollo">
La mayor parte de las pruebas hasta ahora se hizo con el CLI de Claude Code en macOS. Otros agentes (Gemini CLI, Codex, cualquier agente Agent Client Protocol) y otros sistemas se están probando ahora; si usas alguno de ellos, [la documentación para contribuidores](/docs/es/build/testing-other-agents-and-oss/) dice cómo ayudar y dónde reportar.
</Aside>
