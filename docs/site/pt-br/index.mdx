<Aside type="caution" title="O Hark está em desenvolvimento">
A maior parte dos testes até agora foi feita com o CLI do Claude Code no macOS. Outros agentes (Gemini CLI, Codex, qualquer agente Agent Client Protocol) e outros sistemas estão sendo testados agora; se você roda um deles, [a documentação de contribuidor](/docs/pt-br/build/testing-other-agents-and-oss/) diz como ajudar e onde reportar.
</Aside>
